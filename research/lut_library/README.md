# LUT library (research/lut_library)

Curated, licence-verified film-emulation LUTs for the LUT engine (`research/lut/`, owned by the engine agent) and for
synthetic training-data generation. Code and records live here; the downloaded files live in `data/lut_library/`
(git-ignored, 572 MB = 546 MiB on disk). Built on 2026-11-10 by the autonomous lut-library session; the running log is `LOG.md`.

Nothing in this directory touches the owner's 13 Lightroom presets in `~/misc/lut` (parsed by `research/lut/xmp_parser.py`).

## Files

| File | What |
|---|---|
| `manifest.json` | one record per downloaded file (341: 337 LUTs + 4 RawTherapee pp3 presets) with source, licence quote, SHA-256, stock claim, variant, format, size, colour spaces, notes and the `validate.py` result; plus `sources`, `candidates` and `summary` blocks |
| `candidates.json` | every pack found in discovery, approved or rejected, with the reason (34 entries) |
| `source_photos.json` | generator-ready selection of licensed source photographs (1,062 records: 669 tier-1 + 393 tier-2) with licence, attribution, split and a heuristic scene category |
| `validate.py` | .cube / HaldCLUT parser and checks (domain, size, NaN, clipping, grey-axis monotonicity, identity distance) |
| `build_manifest.py` | regenerates `manifest.json` and `candidates.json` from `data/lut_library/` (hashes every file, runs the validator) |
| `source_photos.py` | regenerates `source_photos.json` from the project manifests (no model calls) |
| `LOG.md` | what was searched, read, approved, rejected and why |

## Validation (`validate.py`)

334 of 337 LUT files pass: finite values, inside the declared domain, grey-axis luminance non-decreasing within
1 % of range (8-bit HaldCLUTs carry +-1 code of noise), each output channel increasing on average along its own axis.
The three failures are by design, not corruption: `Negative.png` and `CreativePack-1/ColorNegative.png` invert the
image, and `Rollei IR 400.png` is a tonal inversion of the red channel (infrared look) with half its entries clipped.
42 files pass with a clipping warning (>10 % of entries at the bounds; Polaroid / Velvia Vivid / FP-100c looks).
`identity_rms` in each record is the RMS distance from the identity LUT (0.0016 for the identity TIFF itself; the
film looks lie between 0.03 and 0.33).

## How to load

```python
import numpy as np
from PIL import Image

def load_haldclut(path):                 # PNG/TIFF HaldCLUT -> array [b, g, r, 3] in 0..1 (red varies fastest)
    im = np.asarray(Image.open(path).convert("RGB"), dtype=np.float32) / 255.0
    level = round(im.shape[0] ** (1 / 3)); n = level * level
    return im.reshape(n, n, n, 3)

def load_cube(path):                     # .cube -> array [b, g, r, 3]; DOMAIN_MIN/MAX usually 0..1
    size, rows = None, []
    for line in open(path, encoding="utf-8", errors="replace"):
        s = line.strip()
        if not s or s.startswith("#") or s.upper().startswith(("TITLE", "DOMAIN")): continue
        if s.upper().startswith("LUT_3D_SIZE"): size = int(s.split()[1]); continue
        rows.append([float(x) for x in s.split()[:3]])
    return np.asarray(rows, dtype=np.float32).reshape(size, size, size, 3)
```

Apply with trilinear interpolation on sRGB-encoded input (`input_color_space` in each record). The GlassMeter cubes
and all HaldCLUTs are display-referred sRGB -> sRGB. The filmlab Vision3 files are a two-stage chain
(`stage: negative` then `stage: print_2383_rec709`) that expects DaVinci Intermediate / DaVinci Wide Gamut input;
convert sRGB -> linear -> DWG -> DaVinci Intermediate first or leave them to a Resolve-style pipeline. Records carry
`push_pull_stops` (-3..+3 from the RawTherapee file names), `variant_tokens` (cold, warm, hc, alt, generic,
negative, early, v2), `film_stock` (the project canonical id from `filmlook_ml.datasets.film_stock`, e.g.
`kodak_portra_400`, `fuji_pro400h`, `cinestill_800t`), `film_type` and `role`.

Trademark note (from the RawTherapee README, repeated by GlassMeter): stock names in file names only say which film a
LUT is designed to approximate; none of the LUTs is a measurement endorsed by the manufacturers, and the project never
claims film-stock identification.
